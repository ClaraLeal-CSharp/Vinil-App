# VinilApp

Aplicativo Android nativo em Kotlin, Jetpack Compose e Material 3.

## Pré-requisitos

- JDK 17 ou superior
- Android SDK Platform 36 e Build Tools instalados

## VS Code

Abra esta pasta no VS Code. As extensões **Extension Pack for Java**, **Kotlin** e **Gradle for Java** são recomendadas.

## Comandos

```bash
./gradlew assembleDebug
./gradlew installDebug
```

O APK de depuração é gerado em `app/build/outputs/apk/debug/app-debug.apk`.
